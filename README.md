## 🇩🇪 Deutsch

### 📖 Über das Spiel
**Glitch Protocol: Breach OS** ist eine immersive Cyberpunk-Hacking-Simulation im Stil einer voll funktionsfähigen Kali-Linux/Desktop-Umgebung für Android. 

Als aufstrebender Hacker in Berlin startest du mit einem alten ThinkPad in einem feuchten Kellerzimmer im Wedding. Dein Ziel: Sicherheitslücken in Unternehmensnetzwerken aufspüren, lukrative Kopfgelder erbeuten, Krypto-Mining-Hardware zusammenschrauben und dir den Weg bis an die Spitze der Cyber-Unterwelt freizuhacken.

---

### 🎮 Hauptfeatures

* 🐉 **Interaktiver Kali Desktop:** Frei verschiebbare Multi-Windows, Taskbar, Live-Uhrzeit (Europe/Berlin) und anpassbare Arbeitsumgebung.
* 💻 **Vollwertiges Cyber-Terminal:** Echte Befehlssyntax für Multi-Step-Angriffe:
  * 
map -sV <IP> – Port- und Dienst-Erkennung
  * sqlmap -u <Target> --dbs – Automatisierte Datenbank-Injektion
  * hydra -l admin -P pass.txt <IP> rdp – Paralleles Login-Cracking
  * irodump-ng & hashcat – WLAN 4-Way Handshake Capture & Hash-Cracking
  * exfiltrate <ID> – Gesicherte Daten exfiltrieren & Beute kassieren
  * shred – Spuren verwischen und Polizei-Heat abbauen
* 🗺️ **Maps & Deutschland-Navigation:** Interaktive Deutschlandkarte mit Zoom-, Drag- und Filterfunktionen für dynamisch generierte Firmenziele.
* ⛏️ **Modulares Bitcoin Mining Rig:**
  * Baue dein eigenes Mining-Rig aus Einzelteilen zusammen (*Open-Air Frame*, *1200W Titanium Netzteil*, *RTX 4090*, *Antminer S19 Pro ASIC*).
  * Verbinde deine Hardware mit dem *Stratum V2 Bitcoin Node* und schürfe echte Satoshis.
* 🌐 **ClearWeb & Tor Browser (.onion):**
  * Kaufe PC-Hardware auf HardwareDirect.de.
  * Durchstöbere Darknet-Märkte auf ShadowZero.onion nach Zero-Day Exploits.
  * Miete neue Verstecke auf DarkImmo.onion.
* 🏢 **Immobilien & Progression:** Ziehe von der feuchten Kellerwohnung über eine Spandauer Schraubergarage bis in das kugelsichere Luxus-Penthouse in Berlin-Mitte.

## 🇬🇧 English

### 📖 About the Game
**Glitch Protocol: Breach OS** is an immersive cyberpunk hacking simulation designed as an interactive Kali Linux-inspired mobile desktop operating system for Android.

Starting from a damp basement hideout in Berlin-Wedding with a worn-out ThinkPad, you ascend through the ranks of the cyber underground: scan vulnerable targets across Germany, crack security protocols, assemble high-end Bitcoin mining rigs, and build a digital empire.

---

### 🎮 Key Features

* 🐉 **Interactive Cyber Desktop:** Smooth movable multi-windows, taskbar status indicators, real-time Berlin clock, and customizable layouts.
* 💻 **Realistic Terminal Engine:** Execute complex cyber kill-chains with real tool commands (
map, sqlmap, hydra, hashcat, exfiltrate, shred).
* 🗺️ **Maps & Tactical Scouting:** Interactive, zoomable navigation map pinpointing scalable daily corporate targets with unique vulnerabilities.
* ⛏️ **Modular Bitcoin Mining Rig:**
  * Assemble physical mining components (*Open-Air Frame*, *1200W Titanium PSU*, *RTX 4090 GPUs*, *Antminer S19 Pro ASIC*).
  * Connect to a Stratum V2 Bitcoin Node and earn unconfirmed Satoshi block rewards.
* 🌐 **ClearWeb & Tor Darknet Portals:**
  * Purchase hardware components on HardwareDirect.de.
  * Trade 0-day exploits on ShadowZero.onion.
  * Upgrade hideouts via DarkImmo.onion.
* 🏢 **Hideout Progression:** Upgrade from a gritty basement apartment to high-tech industrial garages and bulletproof skyline penthouses in Berlin-Mitte.
